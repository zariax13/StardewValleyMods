### 📖 Description

**Excalibur Scarecrow** adds a mythical sword embedded in the earth that combines the functions of a scarecrow and an automatic watering system.

#### ✨ Key Features

- 🗡️ **Crop Protection**: Functions as a scarecrow within a configurable radius
- 💧 **Automatic Watering**: Waters all nearby crop tiles every morning
- 🌊 **Visual Animation**: Magical wave effects when entering the farm
- ⚙️ **Fully Configurable**: Adjust radius, sprite, and speed from the configuration menu
- 🎨 **Multiple Sprites**: Choose from different designs

---

### 📥 Installation

#### Requirements
- [Stardew Valley](https://store.steampowered.com/app/413150/Stardew_Valley/) v1.6.0+
- [SMAPI](https://smapi.io/) v4.0.0+

#### Steps
1. **Download the mod** from Nexus Mods or GitHub
2. **Extract the** `.zip` file into the `Mods` folder of Stardew Valley:
3. **Launch the game** with SMAPI
4. **You'll receive a letter** with the sword when you start your save

---

### ⚙️ Configuration

The mod is configurable. You can adjust parameters in-game using **Generic Mod Config Menu** or by manually editing the `config.json` file.

| Parameter | Description | Values | Default |
|-----------|-------------|---------|---------|
| `WaterRadius` | Watering/protection radius in tiles | 1-30 | 6 |
| `SpriteIndex` | Sword design | 0-9 | 1 |
| `WaveSpeedSeconds` | Interval between Waves | 0.1-2.0 seconds | 1.7 |
| `ParticlesAlwaysActive` | Activate permanent animation | yes / no | yes |

#### 📂 Configuration Location
`Stardew Valley/Mods/ExcaliburScarecrow/config.json`

> **Note**: The `config.json` file is automatically created the first time you run the mod.

---

### 🎮 How to Use

1. **Get the sword**: You'll receive a letter when starting your save
2. **Place the sword**: Select the sword from your inventory and place it on the ground
3. **That's it!**: The sword will automatically protect and water your crops

## 🐛 Troubleshooting

### The sword doesn't appear
- Verify that the mod is in the correct folder
- Restart the game completely

### Doesn't water crops
- Make sure the radius is sufficient
- Verify that crops are within the radius
- Check the `WaterRadius` configuration

### Game fails to load
- Update SMAPI to the latest version
- Check for conflicts with other mods
- Consult the `SMAPI-latest.log` file
