---

### 📖 Descripción

**Excalibur Scarecrow** añade una espada mítica clavada en la tierra que combina las funciones de un espantapájaros y un sistema de riego automático.

#### ✨ Características Principales

- 🗡️ **Protección de Cultivos**: Funciona como espantapájaros dentro de un radio configurable
- 💧 **Riego Automático**: Riega todas las parcelas cercanas cada mañana
- 🌊 **Animación Visual**: Efectos de olas mágicas al entrar a la granja
- ⚙️ **Totalmente Configurable**: Ajusta el radio, el sprite y la velocidad desde el menú de configuración
- 🎨 **Múltiples Sprites**: Elige entre diferentes diseños

---

### 📥 Instalación

#### Requisitos
- [Stardew Valley](https://store.steampowered.com/app/413150/Stardew_Valley/) v1.6.0+
- [SMAPI](https://smapi.io/) v4.0.0+

#### Pasos
1. **Descarga el mod** desde Nexus Mods o GitHub
2. **Extrae el** archivo `.zip` en la carpeta `Mods` de Stardew Valley
3. **Inicia el juego** con SMAPI
4. **Recibirás una carta** con la espada al cargar tu partida

---

### ⚙️ Configuración

El mod es configurable. Puedes ajustar los parámetros en el juego usando **Generic Mod Config Menu** o editando manualmente el archivo `config.json`.

| Parámetro | Descripción | Valores | Predeterminado |
|-----------|-------------|---------|----------------|
| `WaterRadius` | Radio de riego/protección en casillas | 1-30 | 6 |
| `SpriteIndex` | Diseño de la espada | 0-9 | 1 |
| `WaveSpeedSeconds` | Intervalo entre olas de regado | 0.1-2.0 segundos | 1.7 |
| `ParticlesAlwaysActive` | Activar animación permamente | si / no | si |

#### 📂 Ubicación de Configuración
`Stardew Valley/Mods/ExcaliburScarecrow/config.json`

> **Nota**: El archivo `config.json` se crea automáticamente la primera vez que ejecutas el mod.

## 🐛 Solución de Problemas

### La espada no aparece
- Verifica que el mod esté en la carpeta correcta
- Reinicia el juego completamente

### No riega los cultivos
- Asegúrate de que el radio sea suficiente
- Verifica que los cultivos estén dentro del radio
- Comprueba la configuración de `WaterRadius`

### El juego no carga
- Actualiza SMAPI a la última versión
- Verifica conflictos con otros mods
- Consulta el archivo `SMAPI-latest.log`
